# 06 — Departamento de Inversiones y Patrimonio MG

## Misión
Impulsar la escalabilidad de activos, brindar asesoría de alto valor a inversionistas inmobiliarios y seleccionar oportunidades estratégicas para la adquisición de patrimonio propio de MG Propiedades.

**Este departamento es el motor de crecimiento patrimonial del negocio. Sin inversiones, no hay escalabilidad.**

---

## 1. Análisis Financiero e Inmobiliario

### 1.1 Métricas Inmobiliarias

**Referencia**: `PLANTILLAS/FINANZAS/calculadora_rentabilidad.md`

| Métrica | Fórmula | Interpretación |
| :--- | :--- | :--- |
| **ROE** | (Venta - Compra) / (Pie + Gastos) | Retorno sobre patrimonio |
| **ROA** | (Ingresos - Gastos) / Valor | Retorno sobre activos |
| **ROI Apalancado** | (Ingresos - Gastos - Dividendo) / (Pie + Gastos) | Retorno con crédito |
| **Cap Rate** | Arriendo anual / Valor | Rentabilidad bruta |
| **Tasa de Vacancia** | Meses desocupados / 12 | Tiempo sin arriendo |

### 1.2 Proyecciones de Plusvalía

**Evaluación de desarrollo urbano, conectividad y comportamiento comercial por sectores.**

| Factor | Pregunta clave |
| :--- | :--- |
| **Desarrollo urbano** | ¿Hay proyectos de infraestructura? |
| **Conectividad** | ¿Hay proyectos de metro, autopistas? |
| **Comercio** | ¿Hay nuevos malls, supermercados? |
| **Educación** | ¿Hay colegios, universidades? |
| **Salud** | ¿Hay hospitales, clínicas? |

**Zonas emergentes**: aquellas con desarrollo pendiente y precios aún bajos.

### 1.3 Modelos de Compra

| Modelo | Perfil de riesgo | Plazo de entrega |
| :--- | :--- | :--- |
| **En blanco** | Mayor riesgo, mayor rentabilidad | 18-24 meses |
| **En verde** | Riesgo medio, rentabilidad media | 6-12 meses |
| **Entrega inmediata** | Menor riesgo, menor rentabilidad | 0-3 meses |

## 2. Asesoría para Clientes Inversionistas (VIP)

### 2.1 Tipos de Inversionista

| Tipo | Filosofía | Horizonte |
| :--- | :--- | :--- |
| **Renta rápida** | Comprar, arrendar, flujo inmediato | Corto plazo |
| **Plusvalía** | Comprar, esperar, vender | Mediano plazo |
| **Acumulación** | Comprar, acumular, renta pasiva | Largo plazo |

**Perfil de riesgo:**
- **Conservador**: prefiere entrega inmediata, menor rentabilidad, menor riesgo.
- **Moderado**: acepta verde, rentabilidad media.
- **Agresivo**: acepta blanco, mayor rentabilidad, mayor riesgo.

### 2.2 Gestión de Portafolios

**Asesoría personalizada a clientes con múltiples activos.**

**Servicios:**
- Análisis de portafolio actual
- Recomendación de diversificación
- Estrategia de apalancamiento
- Estrategia de salida

### 2.3 Estrategias de Apalancamiento

**Evaluación de financiamiento bancario, mutuarias y estructuras tributarias.**

| Estrategia | Descripción |
| :--- | :--- |
| **Crédito hipotecario** | Financiamiento tradicional |
| **Mutuaria** | Financiamiento no bancario |
| **Leasing** | Arriendo con opción de compra |
| **Estructura tributaria** | Optimización de impuestos |

### 2.4 Estrategia de Salida

**Asesoramiento sobre el momento óptimo para la venta o refinanciamiento.**

**Cuándo vender:**
- Cuando la plusvalía se estanca.
- Cuando la rentabilidad baja.
- Cuando hay una mejor oportunidad.
- Cuando el cliente necesita liquidez.

**Cuándo refinanciar:**
- Cuando las tasas bajan.
- Cuando el valor de la propiedad sube.
- Cuando se necesita capital para otra inversión.

## 3. Adquisición y Patrimonio Propio MG

### 3.1 Caza de Oportunidades (Remates / Oportunidades)

**Identificación de activos bajo precio de mercado para compra directa corporativa.**

**Fuentes:**
- Remates judiciales
- Remates bancarios
- Oportunidades de corredores
- Propiedades con urgencia de venta

**Criterios de selección:**
- Precio bajo mercado (≥ 15%)
- Ubicación estratégica
- Potencial de plusvalía
- Rentabilidad ≥ 6%

### 3.2 Evaluación de Riesgo Patrimonial

**Análisis de factibilidad antes de la adquisición directa.**

**Checklist:**
- Estudio de títulos
- Verificación de gravámenes
- Estado de conservación
- Rentabilidad proyectada
- Estrategia de salida
