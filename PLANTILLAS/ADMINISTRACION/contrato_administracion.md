## 4. Servicios Incluidos

El mandato incluye:

- ( ) Cobranza mensual del canon
- ( ) Verificación de pagos de servicios básicos
- ( ) Verificación de gastos comunes al día
- ( ) Coordinación de mantención ordinaria
- ( ) Coordinación de mantención extraordinaria (con aprobación del propietario)
- ( ) Renovación de contrato de arriendo
- ( ) Gestión de morosidad
- ( ) Liquidación mensual al propietario

---

## 5. Autorizaciones

El mandante autoriza a MG Propiedades a:

- ( ) Cobrar el canon de arriendo en su nombre
- ( ) Pagar gastos comunes y servicios básicos
- ( ) Coordinar reparaciones menores (hasta $______)
- ( ) Contratar servicios técnicos
- ( ) Notificar al arrendatario sobre reajustes

---

## 6. Obligaciones de MG Propiedades

MG Propiedades se compromete a:

- Transferir el canon al propietario dentro de los primeros 5 días hábiles del mes.
- Informar mensualmente sobre el estado de la propiedad.
- Gestionar la morosidad según protocolo.
- Coordinar la mantención necesaria.
- Mantener informado al propietario sobre cualquier novedad.
