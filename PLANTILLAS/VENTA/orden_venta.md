---

## 4. Autorizaciones

El mandante autoriza a MG Propiedades a:

- ( ) Publicar la propiedad en portales inmobiliarios
- ( ) Publicar la propiedad en redes sociales
- ( ) Instalar letrero en la propiedad
- ( ) Realizar visitas con clientes previamente calificados
- ( ) Solicitar documentación al comprador
- ( ) Firmar contrato de compraventa en representación del mandante
- ( ) Tramitar documentación faltante (con reembolso)

## 6. Declaraciones del Mandante

El mandante declara que:

- Es el legítimo dueño de la propiedad.
- La propiedad no tiene limitaciones que impidan su venta.
- La información proporcionada es verídica.
- Autoriza a MG Propiedades a realizar las gestiones necesarias.
