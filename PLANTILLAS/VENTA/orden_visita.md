# Orden de Visita — Registro de Visita a Propiedad

## Propósito
Registrar la visita de un cliente a una propiedad. Es el único medio de prueba si el cliente "salta" al corredor.

**Este documento es obligatorio antes de mostrar cualquier propiedad.**

## 4. Condiciones

El cliente declara que:

- ( ) Visita la propiedad por primera vez
- ( ) Fue contactado por MG Propiedades
- ( ) No fue contactado por otro corredor para esta propiedad
- ( ) Reconoce que MG Propiedades es el corredor que le mostró la propiedad

**Comisión:**
- Venta: 2% + IVA (comprador) + 2% + IVA (vendedor)
- Arriendo: 50% + IVA del primer canon (cada parte)

**Momento de pago:**
- ( ) Al firmar contrato de compraventa en notaría
- ( ) Al inscribir en el Conservador de Bienes Raíces
- ( ) Al firmar contrato de arriendo

---

## 5. Cláusulas

1. El cliente se compromete a no contactar directamente al propietario para realizar la operación sin la intervención de MG Propiedades.
2. Si el cliente realiza la operación directamente con el propietario, MG Propiedades tiene derecho a cobrar la comisión correspondiente.
3. Cualquier conflicto será resuelto por un árbitro arbitrador.
