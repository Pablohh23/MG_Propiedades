# 05 — Departamento de Administración de Arriendos

## Misión
Asegurar la generación de ingresos recurrentes para MG Propiedades mediante la gestión integral de contratos de arrendamiento, cobro puntual de rentas, reajustes, finiquitos y mantención física de inmuebles.

**Este departamento es el motor de ingresos recurrentes del negocio. Sin administración, no hay flujo estable.**

---

## 1. Gestión de Contratos y Reajustes

### 1.1 Evaluación de Solvencia del Arrendatario

**Requisitos mínimos:**

| Requisito | Especificación |
| :--- | :--- |
| **Renta líquida** | ≥ 3 veces el canon de arriendo |
| **Contrato de trabajo** | Plazo indefinido |
| **DICOM** | Sin deudas |
| **Aval** | Con misma solvencia que arrendatario |
| **Cédula de identidad** | Vigente |
| **Certificado de cotizaciones AFP** | Últimos 12 meses |

**Alternativa sin aval:**
- 12 cheques (uno por mes)
- Contrato por 1 año fijo (no 13 meses)
- Renovación con nuevos cheques

### 1.2 Contrato de Arriendo

**Cláusulas obligatorias:**

| Cláusula | Descripción |
| :--- | :--- |
| **Acuerdo entre las partes** | Arrendador y arrendatario |
| **Descripción del inmueble** | Dirección, comuna, rol |
| **Renta de arrendamiento** | Monto y forma de pago |
| **Reajustabilidad** | IPC o UF cada 6 meses o 1 año |
| **Plazo del contrato** | 1 año fijo + renovación mensual |
| **Fiador solidario** | Si aplica (o 12 cheques) |
| **Gastos comunes y servicios** | Quién paga qué |
| **Prohibiciones** | No subarrendar, no cambios estructurales |
| **Mantención y mejoras** | Responsabilidades |
| **Restitución** | Estado de devolución |
| **Resolución de conflictos** | Árbitro arbitrador |
| **Acta de entrega** | Inventario al inicio |

### 1.3 Reajustes Automáticos

**Aplicación periódica de variaciones en UF o IPC.**

| Periodicidad | Índice | Aplicación |
| :--- | :--- | :--- |
| **Semestral** | IPC | Cada 6 meses |
| **Anual** | IPC o UF | Cada 12 meses |

**Procedimiento:**
1. Calcular variación del índice en el período.
2. Aplicar al canon vigente.
3. Notificar al arrendatario por escrito.
4. Registrar en el contrato (anexo).

## 2. Cobranza y Liquidación a Propietarios

### 2.1 Recaudación de Rentas

**Control de pagos de arriendo en la fecha estipulada.**

| Día | Acción |
| :--- | :--- |
| **Día 1** | Envío de recordatorio al arrendatario |
| **Día 5** | Verificación de pago |
| **Día 6** | Si no pagó: contacto telefónico |
| **Día 10** | Si no pagó: carta de aviso |
| **Día 15** | Si no pagó: gestión de cobranza |

### 2.2 Gestión de Morosidad

**Protocolo de cobranza extrajudicial.**

| Etapa | Acción |
| :--- | :--- |
| **1. Recordatorio** | WhatsApp / correo al arrendatario |
| **2. Llamada** | Contacto telefónico |
| **3. Carta de aviso** | Carta formal con plazo |
| **4. Cobranza extrajudicial** | Empresa de cobranza |
| **5. Cobranza judicial** | Abogado (si es necesario) |

**Herramientas:**
- **Aval**: si hay aval, se cobra al aval.
- **Cheques**: si hay cheques, se cobran.
- **Seguro de arriendo**: si hay seguro, se activa.

### 2.3 Liquidación Mensual al Propietario

**Transferencia del canon al propietario descontando honorarios.**

| Concepto | Monto |
| :--- | :--- |
| **Canon de arriendo** | $ |
| **(-) Honorarios administración** | 8-10% |
| **(-) Gastos (si aplica)** | $ |
| **(=) Transferencia al propietario** | $ |

**Plazo**: dentro de los primeros 5 días hábiles del mes.

## 3. Inspección y Mantención de Inmuebles

### 3.1 Acta de Entrega y Recepción

**Inventario detallado del estado del inmueble.**

**Contenido:**
- Fecha
- Datos del arrendador y arrendatario
- Dirección del inmueble
- Inventario por ambiente (living, cocina, baños, dormitorios, terraza)
- Estado de cada elemento (nuevo, bueno, regular, malo)
- Lectura de medidores (luz, agua, gas)
- Fotos
- Firma de ambas partes

### 3.2 Gastos Comunes y Cuentas

**Verificación de pagos al día.**

| Servicio | Verificación |
| :--- | :--- |
| **Gastos comunes** | Certificado de administración |
| **Luz** | Última boleta pagada |
| **Agua** | Última boleta pagada |
| **Gas** | Última boleta pagada |
| **Internet** | Última boleta pagada |

### 3.3 Mantención Operativa

**Coordinación de reparaciones y servicios técnicos.**

| Tipo | Responsable |
| :--- | :--- |
| **Mantención ordinaria** | Arrendatario |
| **Mantención extraordinaria** | Arrendador |
| **Reparaciones estructurales** | Arrendador |
| **Reparaciones por mal uso** | Arrendatario |

### 3.4 Finiquito al Término del Contrato

**Devolución de garantía y cierre del contrato.**

| Concepto | Acción |
| :--- | :--- |
| **Inspección final** | Verificar estado del inmueble |
| **Comparación con acta inicial** | Detectar daños |
| **Descuentos** | Si hay daños, descontar de garantía |
| **Devolución de garantía** | Al arrendatario (si no hay daños) |
| **Cierre de servicios** | Notificar a compañías |

| KPI | Meta |
| :--- | :--- |
| Contratos administrados | 5+ |
